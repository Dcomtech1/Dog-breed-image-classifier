# Image Classification for a City Dog Show 🐶

## Project Overview
This project uses a pre-trained Convolutional Neural Network (CNN) to classify images as **dogs** or **not dogs**, and to identify dog breeds.

The project compares three CNN architectures:
- AlexNet
- VGG
- ResNet

The goal is to determine the best model based on:
- Classification accuracy
- Dog breed identification accuracy
- Runtime performance

## Technologies Used
- Python
- Pre-trained CNN models (ImageNet)

## How to Run
```bash
python main.py --arch resnet
